# Γόρττολ — Το κυπριακό Wordle

Μια στατική, responsive ιστοσελίδα παιχνιδιού στα ελληνικά. Δεν απαιτεί εγκατάσταση, server, libraries ή build step.

## Δοκιμή στον υπολογιστή σου

Άνοιξε το `index.html` σε οποιοδήποτε σύγχρονο browser.

## Δημοσίευση με GitHub Pages (δωρεάν)

1. Συνδέσου στο [GitHub](https://github.com/) και δημιούργησε ένα νέο repository, π.χ. `gorttol`.
2. Κάνε upload τα `index.html` και `README.md` στον βασικό φάκελο του repository (root) και κάνε commit.
3. Άνοιξε **Settings → Pages**.
4. Στο **Build and deployment**, διάλεξε **Deploy from a branch**.
5. Ως branch επίλεξε `main` και folder `/(root)`, μετά πάτησε **Save**.
6. Περίμενε να ολοκληρωθεί το deployment. Το GitHub θα εμφανίσει το URL της σελίδας, συνήθως `https://YOUR-USERNAME.github.io/gorttol/`.

Αν το repository ονομάζεται ακριβώς `YOUR-USERNAME.github.io`, η διεύθυνση θα είναι `https://YOUR-USERNAME.github.io/`.

## Παιχνίδι

- Λέξεις 5, 6 ή 7 γραμμάτων, με έξι προσπάθειες.
- Ελληνικό πληκτρολόγιο στην οθόνη ή φυσικό πληκτρολόγιο.
- Πράσινο = γράμμα στη σωστή θέση, κίτρινο = σωστό γράμμα σε λάθος θέση, γκρι = γράμμα που δεν χρειάζεται.
- Οι κρυφές λέξεις επιλέγονται από τη λίστα που δόθηκε για το παιχνίδι. Οι προσπάθειες δεν περιορίζονται στη λίστα, ώστε να μπορείς να πληκτρολογείς ελεύθερα.
- Δεν χρησιμοποιούνται cookies, analytics ή εξωτερικές βιβλιοθήκες.

## Αλλαγή λέξεων

Οι λίστες βρίσκονται στην αρχή του JavaScript μέσα στο `index.html`, στο αντικείμενο `rawWords`, χωρισμένες σε μήκη `5`, `6` και `7`.
